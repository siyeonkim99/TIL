## 이 사이트 쓰는 법

실습 파일(`.py`)에 아래 5개 기호만 주석으로 달면 노트가 자동으로 만들어집니다.

| 기호 | 뜻 |
|---|---|
| `#==` | 섹션 제목 |
| `#>` | 설명 (여러 줄은 한 문단으로 합쳐짐) |
| `#!` | 막혔던 부분 → 경고 박스 + 바로 아래 코드 줄 강조 |
| `#?` | 나중에 볼 것 → 페이지 하단 체크박스 |
| `#@@@` | 따로 팔 큰 주제 → GitHub 이슈로 생성 |

`git push` 하면 노트 변환 → 이슈 생성 → 사이트 배포가 자동으로 돕니다.
